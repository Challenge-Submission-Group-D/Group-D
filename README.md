# Group_d

SEASONAL VACCINE PREDICTION SYSTEM

Project Title:
Seasonal Vaccine Prediction using Machine Learning

Project Overview:
This project predicts whether an individual is likely to receive a seasonal vaccine based on demographic, behavioral, health, and opinion-related factors. The solution was developed as part of a machine learning hackathon and includes data preprocessing, exploratory data analysis, feature engineering, model development, evaluation, and prediction generation.

Dataset:
- Training Dataset: dataset_A_training.csv
- Testing Dataset: dataset_A_testing.csv
- Target Variable: seasonal_vaccine
- ID Column: respondent_id

Project Workflow:
1. Data Loading and Inspection
2. Missing Value Handling
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Data Encoding and Scaling
6. Model Training
7. Model Evaluation
8. Prediction Generation
9. Submission File Creation

Data Preprocessing:
- Median imputation for numerical features
- Mode imputation for categorical features
- Label Encoding for categorical variables
- StandardScaler used for feature scaling

Feature Engineering:
- Risk Awareness Score
- Behaviour Score
- Vaccine Opinion Score

Machine Learning Models:
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Gradient Boosting Classifier
- XGBoost Classifier

Evaluation Metrics:
- Accuracy Score
- ROC-AUC Score
- Classification Report
- Confusion Matrix
- Cross Validation

Visualizations:
- Correlation Heatmap
- Vaccine Uptake by Age Group
- Vaccine Uptake by Education
- Vaccine Uptake by Gender
- Vaccine Uptake by Income Category
- Confusion Matrix Visualizations

Output Files:
- submission_1.csv
- submission_2.csv
- submission_3.csv
- submission_4.csv
- submission_5.csv

Project Objective:
To build an accurate machine learning solution that predicts seasonal vaccine uptake and assists public health organizations in understanding vaccination behavior patterns.
